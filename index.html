[dir] proposicoes/

Proposições Lógicas

Uma proposição é toda sentença declarativa que pode receber exatamente um valor lógico — verdadeiro (V) ou falso (F) — nunca os dois ao mesmo tempo, e nunca nenhum dos dois.

// são proposições

  • "2 + 2 = 4" — V
  • "O Sol gira em torno da Terra" — F
  • "Curitiba fica no Paraná" — V

// não são proposições

  • Perguntas — "Que horas são?"
  • Ordens e exclamações — "Feche a porta!"
  • Sentenças abertas, com variável sem valor definido — "x + 3 = 10"
  • Opiniões sem critério objetivo de verdade — "Esse filme é ótimo"

Proposições simples (ou atômicas) não usam conectivos e recebem uma letra minúscula: p, q, r, s... Proposições compostas (ou moleculares) juntam duas ou mais proposições simples por meio de conectivos lógicos (que você vê no módulo conectivos/).

Expressões e Conectivos Lógicos

Os conectivos combinam proposições simples em proposições compostas. Cada um tem uma condição exata para ser verdadeiro. Alguns professores usam v no lugar de ∨, ou ^ no lugar de ∧ — o significado é o mesmo.

NomeSímboloLê-seÉ verdadeira quando...
Negação¬p"não p"inverte o valor de p
Conjunçãop ∧ q"p e q"p e q são ambas V
Disjunçãop ∨ q"p ou q"pelo menos uma é V
Condicionalp → q"se p, então q"só é F quando p=V e q=F
Bicondicionalp ↔ q"p se, e somente se, q"p e q têm o mesmo valor

Ordem de precedência (do mais forte para o mais fraco): ¬ , ∧ , ∨ , → , ↔. Parênteses são sempre resolvidos primeiro. Por isso ¬p ∨ q significa (¬p) ∨ q, e não ¬(p ∨ q).

[dir] linguagem-natural/

Linguagem Natural ↔ Proposições Lógicas

Traduzir uma frase para lógica tem duas etapas: (1) identificar as proposições simples e dar uma letra para cada uma, e (2) identificar os conectivos escondidos nas palavras da frase.

// palavras-chave mais comuns

  • "e", "mas", "porém" → ∧
  • "ou" → ∨
  • "não", "não é verdade que" → ¬
  • "se ..., então ..." → →
  • "... se, e somente se, ..." → ↔

// exemplo

"Se chover, então levarei o guarda-chuva."
p: "Chove."  |  q: "Levarei o guarda-chuva."
Tradução: p → q

Para traduzir no sentido contrário — da lógica para a linguagem natural — basta substituir cada letra pelo significado da proposição e reescrever o conectivo por extenso. Preste atenção nas negações: em português, o "não" pode vir antes ou depois da proposição na frase.

[dir] tabela-verdade/

Tabela-Verdade

A tabela-verdade mostra o valor lógico de uma proposição composta para todas as combinações possíveis de valores das proposições simples que a formam.

Número de linhas: se a proposição tem n proposições simples diferentes, a tabela tem 2ⁿ linhas.

pqp ∧ qp ∨ q
VVVV
VFFV
FVFV
FFFF

// com 2 proposições simples, sempre 4 linhas (2²)

Como montar: liste todas as combinações de V/F das proposições simples, depois calcule os conectivos de maior precedência primeiro, coluna por coluna, até chegar no resultado final.

// classificação pelo resultado final

  • Tautologia — resultado é V em todas as linhas
  • Contradição — resultado é F em todas as linhas
  • Contingência — o resultado tem pelo menos um V e um F entre as linhas

Formas Normais (FND e FNC)

Toda fórmula proposicional pode ser reescrita em um formato padronizado usando as equivalências tautológicas. As duas formas cobradas são:

// os dois formatos

  • FND — disjunção de conjunções: ( ∧ ) ∨ ( ∧ )
  • FNC — conjunção de disjunções: ( ∨ ) ∧ ( ∨ )

Nas duas formas valem as mesmas restrições: só podem aparecer os conectivos ¬ , ∨ , ∧ (nada de → ou ↔), e a negação só pode ficar sobre proposições simples — nunca sobre ∨ ou ∧. A diferença é o aninhamento: a FNC não contém ∨ sobre ∧, e a FND não contém ∧ sobre ∨.

Método em 3 passos:

// passo 1 — eliminar → e ↔

  • A → B ≡ ¬A ∨ B
  • A ↔ B ≡ (A → B) ∧ (B → A)

// passo 2 — empurrar as negações para dentro

  • De Morgan: ¬(A ∧ B) ≡ ¬A ∨ ¬B  e  ¬(A ∨ B) ≡ ¬A ∧ ¬B
  • Dupla negação: ¬¬A ≡ A

// passo 3 — distribuir até chegar no formato

  • Para FNC, distribua ∨ sobre ∧: A ∨ (B ∧ C) ≡ (A ∨ B) ∧ (A ∨ C)
  • Para FND, distribua ∧ sobre ∨: A ∧ (B ∨ C) ≡ (A ∧ B) ∨ (A ∧ C)

// exemplo completo — p → (q ∧ r)

Passo 1 (condicional): ¬p ∨ (q ∧ r) — isso já é uma FND (disjunção de conjunções; ¬p conta como uma conjunção de um termo só).
Passo 3 (distribuir ∨ sobre ∧): (¬p ∨ q) ∧ (¬p ∨ r) — essa é a FNC.

Repare que fórmulas simples podem já estar nas duas formas ao mesmo tempo: ¬p, p ∨ q e p ∧ q são, simultaneamente, FND e FNC.
